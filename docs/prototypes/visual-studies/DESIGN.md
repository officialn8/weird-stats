Ambient coin movement runs only when visible, with desktop pointer response. The penny reveal, mule arrival, and postmark retain their existing motion. OS reduced motion and the manual motion control disable movement. Semantic coin buttons, actual hidden states, focus restoration, image alternatives, readable diagram explanations, and native source disclosures preserve access without relying on animation.

The scale panels remain in reading order for assistive technology; visual opacity does not remove their explanations. They contain no hidden interactive controls. The three scale buttons are outside the animated panels. In short viewports the static layout avoids clipping text to fit a sticky scene.
